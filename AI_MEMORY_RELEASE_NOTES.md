# AI Memory Foundation v2.0

## Что добавлено
- Контрольные точки результата: 30 минут, 1 час, 6 часов, 24 часа и 3 дня.
- Направленная оценка PUMP и DIP: рост оценивается по максимуму, падение — по минимуму.
- Статусы SUCCESS / PARTIAL / FAIL.
- Блок AI Memory (24ч) в разделе статистики Telegram-бота.
- Безопасная миграция SQLite: колонка `status` добавляется без удаления существующих данных.
