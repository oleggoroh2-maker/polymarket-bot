# Pilot Readiness Audit v1

Read-only audit for the already frozen Stable Zone Challenger v2 cohort.

- Uses only matured 24h Challenger outcomes.
- Reports ROI, PF, win rate, median, average win/loss, max drawdown and longest loss streak.
- Shows category, entry-price, Early-score and acceleration diagnostics.
- Compares paired 12h -> 24h outcomes.
- Shows Top-5 and Bottom-5 trades for concentration/tail inspection.
- Adds Telegram button: `🧾 Pilot Readiness`.
- Does not change Challenger membership, Live/Trade routing, thresholds or trading behavior.
