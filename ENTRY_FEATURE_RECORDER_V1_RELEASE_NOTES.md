# Entry Feature Recorder v1

Shadow/Paper-only future-only feature capture for newly created Entry Discovery candidates.

Captures frozen price velocity/acceleration, volume/liquidity changes, one-hour price-position metrics, alignment/move-age estimates, and a batched YES order-book snapshot (spread, depths, balance, largest order, imbalance). Existing Entry Discovery outcomes are joined later for 3h/6h/24h feature performance diagnostics.

No Entry v1/v2 threshold, Telegram routing, Trade v2/v3, or live trading behavior is changed.
